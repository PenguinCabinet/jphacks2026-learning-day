# jphacks2026-learning-day
　jphacks2026-learning-dayで構想したプロダクト「TechGrow」のUIです。

　プログラミング学習に取り組んでいる学生をターゲットに、GitHubの活動履歴や学習記録をAIが分析し、技術力がどれくらい成長したのか把握するサービスです。

　原案の作成者はペンギン内閣ではありません。
