# TechGrow - jphacks2026-learning-day
jphacks2026-learning-dayとは、下記の通りです。

> Hack Day開催前の休日を使って、個人参加者のためのチームビルディングをはじめ、デザイン思考やLeanStartup講座をオンラインセミナー形式で開催します。アイデア創発から、Vibe Codingを用いたモックアップ作成までを行い、プロダクト開発の一連の流れを学ぶことができます。

 jphacks2026-learning-dayで私たちのチームが構想したプロダクト「TechGrow」のUIです。

　プログラミング学習に取り組んでいる学生をターゲットに、GitHubの活動履歴や学習記録をAIが分析し、技術力がどれくらい成長したのか把握するサービスです。

　原案の作成者はペンギン内閣ではありません。
